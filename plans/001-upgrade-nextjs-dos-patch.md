## Why this matters

`pnpm audit --prod` reports multiple current advisories against Next.js `16.1.7`, including HIGH-severity Server Components denial-of-service, connection exhaustion, SSRF, and App Router middleware/proxy bypass findings.
The highest patched-version floor among the reported Next.js advisories is `>=16.2.6`.
The latest published stable version observed during reconciliation on 2026-07-10 is `16.2.10`.
This repo pins `next` to `16.1.7`, which is inside the vulnerable range, and the app is built entirely on App Router Server Components.
The audit also reports vulnerabilities through the production `shadcn` dependency tree; plan 004 owns removal of that misplaced CLI dependency.
This is the cheapest high-leverage fix in the audit: one version bump, no API changes expected within the 16.x line.
