## Findings considered and rejected

Recorded so nobody re-audits them:

- **Atlas style retry storm** (events-world-map): claimed infinite retry on failed style loads — actually the catch falls back to the art style and pins the user choice; no loop. Not a finding.
- **Marker/city index mismatch** (events-world-map `repositionMarkers`): `upcomingCities` is `useMemo(..., [])` — computed once, immutable; the index race cannot occur.
- **Unmounted setState in world-globe-select meetup counts**: a `disposed` flag is checked before `setMeetupCounts` (lines 241-243); already correct.
- **Marker click-listener memory leak** (map-shell): removed DOM elements are garbage-collected with their listeners; no explicit removeEventListener needed.
- **Server Action CSRF**: Next.js Server Actions ship origin-checked CSRF protection; nothing to add.
- **SRI hashes on the Turnstile script**: the Cloudflare script updates frequently; SRI would break the widget. Impractical.
- **"Company requests broken for 4 of 6 cities" (RLS city list)**: the server action uses the service-role client which bypasses RLS, so inserts succeed for all six cities. The stale anon policy is real but is folded into plan 002 (dropped there), not a functional outage.
- **`world-map-select.tsx` is dead code**: it is the live WebGL-failure fallback (`world-globe-select.tsx:401-402`). Keep.
- **`new AbortController().signal` discarded** (events-world-map:436): real but harmless — the style JSON is fetched once and cached for the session; wiring cancellation isn't worth the complexity. Noted as out-of-scope in plan 005.
- **SVG/canvas marker redesign** (replacing DOM sprite factories): plausible long-term, but high risk to the product's signature visuals for unproven perf gain. Not worth doing now; revisit only if marker counts grow past ~500 (see plan 006 maintenance notes).
- **`x-forwarded-for` spoofing of the meetup rate limit**: header handling is platform-dependent; on Vercel-style hosts the platform sets it. Deployment configuration concern, not a code fix; a comment already suffices if it ever bites.
